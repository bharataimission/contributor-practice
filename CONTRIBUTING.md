# Contributing to Bharat AI Mission Contributor Practice

Thank you for your interest in learning and contributing!

This repository provides a safe, beginner-friendly environment for practising open-source collaboration. You do not need prior programming experience to participate.

## How you can contribute

You can help by:

- Improving learning materials and documentation.
- Reporting unclear instructions or errors.
- Suggesting new beginner-friendly exercises.
- Improving accessibility and readability.
- Sharing feedback on the learning experience.

## Before making a change

1. Read the relevant exercise instructions.
2. Check whether an issue already exists for the problem you want to address.
3. For substantial changes, open an issue or discuss your proposal before starting.
4. Make only the changes needed to address the task.

## Our contribution workflow

For exercises that use pull requests:

1. Fork the repository when instructed.
2. Create a descriptive branch.
3. Make your change.
4. Review the differences before submitting.
5. Open a pull request with a clear title and explanation.
6. Respond constructively to review feedback.

Follow the specific instructions in each exercise, as not every task requires the same workflow.

## Writing good issues and pull requests

When reporting a problem, explain what you expected, what happened, and how someone else can reproduce it.

When proposing a change, explain:

- What you changed.
- Why the change is useful.
- How you checked your work.
- Any questions or limitations that reviewers should know about.

## Community expectations

We expect everyone to:

- Be respectful, inclusive, and constructive.
- Welcome questions from beginners.
- Give feedback about the work, not the person.
- Respect other contributors' time.
- Acknowledge sources and respect applicable licences.
- Avoid sharing passwords, access tokens, private information, or personal data without permission.

Mistakes are part of learning. Ask questions when you are unsure.

## Important privacy note

Do not publish sensitive personal information in learner profiles, issues, commits, or pull requests. Use only information you are comfortable sharing publicly.

## A note about this training repository

This repository is a learning environment. Completing an exercise does not guarantee that a contribution to another open-source project will be accepted.

Real projects may have additional contribution requirements, licences, security rules, and review processes. Always read their guidelines before contributing.

## Thank you

Every useful contribution helps someone learn. By helping improve this Academy, you are helping more people participate in the open-source AI ecosystem.

**Learn openly. Build collaboratively. Contribute to India's AI journey.**
